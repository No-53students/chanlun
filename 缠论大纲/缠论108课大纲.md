# 缠中说禅《教你炒股票》108 课 · 大纲

> 这套文档是缠师（缠中说禅）2006–2008 年间连载的"教你炒股票"系列，共 108 课。它的特点是**理论课**与**每日解盘（行情评论）**、**杂史故事、心态修炼**穿插进行。以下大纲先给全书逻辑主线，再按篇逐课列要点。

## 〇、全书逻辑主线（学习路线图）

```
理念洗脑(1-5) → 分类思想与均线入门(6-16) → 核心定义:中枢/走势类型/级别(17-20)
→ 三类买卖点+背驰体系(21-30) → 走势分解与当下操作(31-40) → 实战图解(41-60)
→ 形态学精确化:分型/笔/线段(61-80) → 哲学升华+中阴阶段(81-90) → 表里关系+收官(91-108)
```

**一句话概括全书骨架**（第 72 课缠师自己给的"懒人线路图"）：

> **分型 → 笔 → 线段 → 最小级别中枢 → 各级别中枢、走势类型**

全书理论分两大块：**形态学**（几何、无需前提：分型/笔/线段/中枢）与**动力学**（背驰、中枢能量结构，需"价格充分有效市场 + 非完全绝对趋同交易"两个前提）。核心命题是**"走势必完美"**——任何走势必然完成，据此可对走势做完全分类与精确买卖点定位。

## 附：学习建议（怎么读这套文档）

1. **先抓主线，跳过解盘**：纯理论骨干课是 **17–20、21、24、29、30、32、33、35–40、61–67、71–72、77、84、91、102**。每日解盘、杂史（75/76/85/87）、心态课（23/42/52/95/96）可后读。
2. **三个必须反复啃的关卡**：① 第 17 课"走势终完美"与中枢定义；② 第 62–67 课的"分型—笔—线段—特征序列"；③ 第 21/24/29 课的"三类买卖点 + 背驰"。
3. **术语脉络**：均线(吻) → 中枢 → 走势类型(盘整/趋势) → 级别(递归) → 三类买卖点 → 背驰 → 区间套 → 分型/笔/线段 → 中阴/表里关系。
4. **注意两点**：一是"级别"与时间周期图无必然关系（第 84 课），二是全书核心只有一个——**走势必完美**，其余都是由此推演出来的操作推论。
